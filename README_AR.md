# مصنع الرياض للبلك الأوتوماتيكي — Flutter

## محتويات المشروع
- `lib/main.dart`: تشغيل التطبيق والثيم واتجاه RTL.
- `lib/models/product.dart`: نموذج بيانات المنتج.
- `lib/services/product_store.dart`: حفظ المنتجات محليًا باستخدام SharedPreferences.
- `lib/screens/home_screen.dart`: الواجهات الرئيسية، المنتجات، التواصل، معلومات المصنع ولوحة إدارة المنتجات.
- `pubspec.yaml`: مكتبات المشروع.

## التشغيل
1. فك ضغط الملف.
2. افتح مجلد المشروع في بيئة Flutter.
3. نفّذ:
   ```bash
   flutter pub get
   flutter run
   ```
4. لبناء APK:
   ```bash
   flutter build apk --release
   ```
5. ملف APK غالبًا يوجد في:
   `build/app/outputs/flutter-apk/app-release.apk`

## ملاحظات مهمة
- لا توجد أسعار أو مقاسات مفترضة. أضف البيانات الفعلية من «إدارة المنتجات».
- الاتصال وواتساب وخرائط Google تفتح التطبيقات المناسبة على الهاتف.
- لوحة الإدارة محلية وليست محمية بتسجيل دخول، لذلك لا تُعاملها كلوحة آمنة.
- المنتجات محفوظة على الجهاز الذي أُدخلت عليه فقط. لكي تظهر التعديلات لكل العملاء، تحتاج إلى خادم/قاعدة بيانات ومصادقة إدارية آمنة.
- صور المنتجات تقبل حاليًا رابط صورة مباشر. اختيار الصور من معرض الهاتف يحتاج إضافة تنفيذ منفصلة.
- إذا كان البناء على خدمة سحابية يفشل بسبب الشبكة، جرّب البناء محليًا أو أرسل نص رسالة الخطأ.
